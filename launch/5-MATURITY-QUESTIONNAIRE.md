# 5. Maturity questionnaire

The game can't be played publicly until this is filled in (Creator Hub > Neon Coast > Audience /
Maturity & Compliance). Roblox asks you to answer for the **most intense moment** in the game, not
the average.

I couldn't open Roblox's questionnaire from here, so the questions may be worded differently. Below
is every content category it covers, with the answer for Neon Coast and the evidence. Each answer
comes from searching all the scripts (re-checked after the Oct 19 update, 95 scripts), not from the
plan alone.

| Category | Answer | Evidence in the game |
|---|---|---|
| Violence | **Yes, mild and unrealistic, and frequent** (it's core gameplay) | Cops tase wanted players (a 3-second stun), cuff them and send them to prison; spike strips pop tires; cars can ram ambient traffic, which gets knocked away; cars (never people) take crash damage: they smoke, stall and limp, with no explosions or fire. Pedestrians dodge out of the way and are never knocked down. No weapons or guns, no fighting, and no player ever takes damage or dies (nothing in the code changes a player's health). |
| Blood or gore | **None** | No blood anywhere. |
| Crude humor | **None** | Jokes are kid-safe puns on signs and in the Coast Feed ("Gus says: wear sunscreen!", "Man Tries to Outrun Police on a Pool Noodle"). |
| Fear / horror | **None** | No scary content. The gator is scenery and never hurts anyone; the UFO event is lights in the sky and a joke reward. |
| Romance | **None** | |
| Strong language | **None** | No profanity in game text. Player chat is Roblox's filtered chat. |
| Alcohol, drugs, tobacco | **None** | The Club Nova heist is a dance floor and a safe, no drinks. The "smoke" is a getaway smoke cloud from the car, not tobacco. |
| Gambling | **None** | No casino, betting or chance games. |
| Paid random items | **None** | Every purchase shows exactly what you get: 5 passes and 5 fixed cash packs. |
| Free-form user creation | **None** | Players can't build or type text that others see, apart from Roblox chat. |
| Social hangout as the main purpose | **No** | The core is driving, heists and chases. There are crews and a car meet lot, plus standard Roblox chat. |
| Real-world crime | Fictional only | Robbing made-up stores, police arrests and a prison breakout. Your PRD notes Roblox allows fictional robbery and forbids recreating real crimes; nothing here does. |

**Expected label: Mild.** Roblox describes Mild as including *repeated* mild violence, which
matches tasers and arrests being part of every chase. This is your PRD's target (Mild 9+), which
reaches the 9-15 accounts. If any answer would push it to Moderate, check it against the evidence
above first.

**Also from the PRD (account to-do):** turn on ID verification and 2-step verification. Both are
needed before a game can reach players under 16. Do it on TCTRADES_CHRIS; if NightShift Dev is a
group, Roblox may check the group owner's account, so if that's a different account, do it there too.
